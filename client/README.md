# RoomMatch — Flutter client

Flutter frontend for RoomMatch. Run all Flutter commands from this directory.

## Setup

```bash
flutter pub get
flutter run -d chrome
```

Ensure the API is running first (see [../server/README.md](../server/README.md)).

## API URL

Configured in `lib/config/api_config.dart` (default `http://localhost:3000` for Web).
